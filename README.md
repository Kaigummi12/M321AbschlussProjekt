# Abschlussprojekt Modul 321
## Setup
1. .env Datei im root verzeichnis erstellen und die VariablenDB_PASSWORD, MYSQL_ROOT_PASSWORD setzen.
2. Dann docker compose up um alle Container zu starten.
3. Damit sich ein Service mit seiner Datenbank verbinden kann, muss im application.properties das Passwort richtig gesetzt werden.
